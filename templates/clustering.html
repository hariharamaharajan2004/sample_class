How It Works
Automatic Discovery

The system automatically collects unknown objects that don't match existing classes. When enough objects are collected, clustering algorithms can group similar objects together.

Clustering Methods
  • K-Means: Groups objects into a predetermined number of clusters
  • DBSCAN: Automatically determines the number of clusters based on density
Human-in-the-Loop

After clustering, you can review the discovered groups and decide which ones should become new classes. You can also provide meaningful names and descriptions.

Incremental Learning

Once new classes are created, the system will use them to classify future objects, continuously improving its knowledge base.
